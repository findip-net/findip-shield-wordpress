# Contributing

Open an issue before changing external endpoints, privacy behavior, collected event metadata, consent behavior, or WooCommerce checkout integration.

Before submitting a pull request:

1. Run PHP 7.4 syntax checks.
2. Run WordPress Coding Standards and PHPCompatibility checks with `composer lint`.
3. Run the official WordPress Plugin Check tool.
4. Activate the plugin with the current stable WordPress and WooCommerce releases.
5. Describe privacy, consent, compatibility, and external-service impacts in the pull request.

Official maintainer commits, pushes, and releases follow the [FindIP public maintenance identity policy](https://github.com/findip-net/.github/blob/main/CONTRIBUTING.md#maintainer-publishing-identity). They must be performed through `findip-bot` or approved automation and use `FindIP <info@findip.net>` as the Git identity.
