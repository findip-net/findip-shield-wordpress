# WordPress.org directory assets

This directory prepares the display assets that belong at the top level of the
WordPress.org Subversion repository, alongside `trunk/` and `tags/`.

Upload the contents of `assets/` to the SVN repository's `assets/` directory.
Do not include these files in the installable plugin ZIP.

Expected files:

- `banner-772x250.png`
- `banner-1544x500.png`
- `icon-128x128.png`
- `icon-256x256.png`
- `icon.svg`

The artwork is original FindIP branding and is distributed under GPL-2.0-or-later
for use with the FindIP Shield WordPress plugin listing.
